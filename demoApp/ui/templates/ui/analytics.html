Analytics Overview

This dashboard displays Live temperature data from all registered devices. Charts update automatically every 5 seconds with the latest sensor readings retrieved from the IN-CSE.

Data Source: Content Instances (CINs) stored in the oneM2M resource hierarchy

Display: Shows the most recent 50 readings for each device

Update Frequency: Automatic refresh every 5 seconds

Understanding the Charts

X-Axis (Time): Shows the timestamp of each sensor reading

Y-Axis (Temperature): Displays temperature values in Celsius (°C)

Data Points: Each point represents a Content Instance (CIN) created when the device transmitted sensor data

Trends: Line graphs help identify temperature patterns, spikes, and environmental changes over time

Real-Time Updates: New data points are automatically added to the chart

How to get Analytics

1. Make sure at least one device (AE) is registered to the IN-CSE

2. Verify the device is connected via BLE to a gateway (nRF7002 DK)

3. Confirm the gateway's MN-CSE is creating temperature containers

4. Check that Content Instances (CINs) are being created with sensor data

5. Once data is flowing return to this page to view analytics
