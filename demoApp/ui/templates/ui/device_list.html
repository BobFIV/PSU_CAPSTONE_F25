How Devices Register

1. Sensor endpoints (Seeed XIAO nRF54L15) advertise via BLE when disconnected

2. Gateway nodes (nRF7002 DK) scan for available devices and establish connections

3. Connected devices transmit sensor data through UART to the Raspberry Pi

4. The MN-CSE on Raspberry Pi creates AE resources and announces them to the IN-CSE

5. Once announced, devices appear in this dashboard and begin streaming data
