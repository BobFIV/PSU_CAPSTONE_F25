Gateway Overview

Gateways function as Middle Node CSEs (MN-CSEs) in the oneM2M hierarchy. Each gateway runs on a Raspberry Pi 5 paired with an nRF7002 Development Kit, serving as an intermediary between low-power sensor devices and the Infrastructure CSE.

Gateway Functions:

  • Scan for and establish BLE connections with nearby sensor devices (Seeed XIAO nRF54L15)
  • Collect sensor data transmitted via GATT notifications over BLE
  • Forward data to the Raspberry Pi through UART interface
  • Run MN-CSE instance that announces resources to the IN-CSE
  • Maintain connection state and facilitate handover between gateways

Communication: All gateways operate on the same local network and communicate with the IN-CSE via HTTP RESTful APIs following oneM2M standards.

Handover Mechanism

Current Implementation: The system uses an intelligent handover mechanism based on RSSI (Received Signal Strength Indicator) values.

How It Works:

  • Sensor devices periodically send non-connectable BLE advertisements while maintaining active connections
  • All nearby gateways scan for these test advertisements and measure signal strength (RSSI)
  • RSSI data is forwarded to the application layer for analysis
  • The system compares RSSI values across gateways to determine optimal connectivity
  • When signal strength from a different gateway exceeds the current connection, handover is initiated
  • Device disconnects from current gateway and reconnects to the gateway with stronger signal
  • MAC address tracking ensures data continuity throughout the handover process

Benefits: This approach minimizes connection interruptions, optimizes signal quality, and ensures seamless data flow as devices move between gateway coverage areas.

Gateway Setup Instructions

To register a new gateway:

  • 1. Configure Raspberry Pi 5 with ACME-CSE software in MN-CSE mode
  • 2. Connect nRF7002 DK to Raspberry Pi via UART-over-USB
  • 3. Ensure both devices are connected to the same local network as the IN-CSE
  • 4. Configure MN-CSE with parent CSE URL pointing to IN-CSE's local IP
  • 5. Start MN-CSE service - registration will occur automatically
  • 6. Gateway will appear in this dashboard once successfully registered

Gateway Architecture

Hardware Components:

  • Raspberry Pi 5: Hosts MN-CSE instance, manages oneM2M communication, processes sensor data
  • Nordic nRF7002 DK: Handles BLE scanning, connection management, and GATT client operations
  • UART Interface: Connects nRF7002 DK to Raspberry Pi for bidirectional data transfer

Software Stack:

  • ACME-CSE: Python-based oneM2M middleware running as MN-CSE
  • Zephyr RTOS: Real-time operating system on nRF7002 DK for BLE management
  • Custom Firmware: Connection management, whitelist filtering, RSSI monitoring
