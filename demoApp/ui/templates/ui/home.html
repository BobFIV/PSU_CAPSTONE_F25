Welcome to the IoT Handover Framework

A seamless, oneM2M-compliant system for managing IoT device connectivity across multiple gateways

About This Project

The IoT Handover Framework is a Penn State Capstone project (Fall 2025) that establishes a seamless handover architecture between multiple gateways (MN-CSEs) and an Infrastructure CSE using the oneM2M ACME framework.

System Architecture:

  • Sensor Layer: Low-power IoT devices (Seeed Studio XIAO nRF54L15) transmit environmental data via Bluetooth Low Energy (BLE)
  • Gateway Layer: Edge gateways (Nordic nRF7002 DK + Raspberry Pi 5) collect sensor data and manage device connections
  • oneM2M Layer: Infrastructure CSE (IN-CSE) controls data flow and manages Middle Node CSEs (MN-CSEs) according to oneM2M standards
  • Application Layer: This web dashboard visualizes sensor data, device status, and gateway connections

Key Features:

  • Live temperature, humidity, and pressure monitoring from multiple sensor endpoints
  • Handover mechanism using signal strength analysis
  • Device tracking ensures data flow across gateway transitions
  • oneM2M-compliant resource hierarchy for standardized IoT communication
  • Notifications for instant data updates

Current Status: The system is fully integrated from embedded devices through cloud infrastructure. Active handover implementation is in progress, which allows devices to switch between gateways based on signal strength.

System Configuration

IN-CSE Endpoint: The Infrastructure CSE is hosted locally and manages the entire oneM2M resource hierarchy.

Communication Protocol: All components communicate via APIs following oneM2M standards.

Data Flow: Sensor → BLE → Gateway (nRF7002 DK) → UART → Raspberry Pi (MN-CSE) → IN-CSE → CloudAppAE (Dashboard)

Update Frequency: Dashboard refreshes sensor data every 5 seconds from the IN-CSE.
